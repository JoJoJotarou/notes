当前的学习主线：用 **Swift** 和 **SwiftUI** 开发 **macOS** 应用。

## 子目录规划

新笔记按下面的子目录放置（目录在写第一篇笔记时创建，每个子目录都配一个 `index.md` 作为导航页）：

| 目录 | 内容 |
| --- | --- |
| `swift/language/` | Swift 语言本身：语法、类型系统、协议、泛型、并发（async/await、Actor）、内存管理 |
| `swift/swiftui/` | SwiftUI：视图、布局、状态管理（`@State` / `@Observable` / `@Environment`）、导航、动画 |
| `swift/macos/` | macOS 应用开发：窗口与菜单栏、AppKit 互操作、沙盒与权限、打包签名与发布 |
| `swift/tooling/` | Xcode、Swift Package Manager、调试、测试、Instruments |
