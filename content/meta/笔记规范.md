本规范让人和 AI 助手都能一致地整理、检索笔记。新增或修改笔记时请遵守。

## 1. 目录结构

```text
content/
├── index.md            # 首页：链接到每个主题的 index
├── swift/              # Swift 语言、SwiftUI、macOS 开发（子目录见 swift/index.md）
│   └── index.md
├── inbox/              # 未分类的笔记，之后再整理
│   └── index.md
├── meta/               # 关于本站自身的说明（如本规范）
└── assets/             # 图片等附件（按主题建子目录，如 assets/swift/）
```

- 每个主题目录（包括子目录）都要有一个 `index.md` 作为导航页
- 新的顶层主题：在 `content/` 下新建目录 + `index.md`，并在首页 `content/index.md` 加链接
- 不确定放哪里时，放进 `inbox/`

## 2. Frontmatter（每篇笔记必填）

```yaml
---
title: SwiftUI 中的 @Observable 宏      # 必填：页面标题（中文/英文均可）
date: 2026-10-24                        # 必填：创建日期 YYYY-MM-DD
tags:                                   # 必填：至少一个，小写英文或中文，用 - 连接词
  - swift
  - swiftui
  - state-management
aliases:                                # 可选：别名，便于 [[别名]] 链接和搜索
  - Observable
related:                                # 可选：相关笔记（双链），用引号包裹
  - "[[swift/swiftui/state-and-binding]]"
draft: false                            # 可选：true 则不发布到网站
---
```

- `tags` 第一个通常写主题（如 `swift`），后面写更细的概念
- `updated` 不需要手写：网站会从 git 记录读取修改时间
- 正文**不要**再写与 `title` 相同的一级标题 `#`，从 `##` 开始

## 3. 文件命名

- 使用**小写英文 + 连字符**（kebab-case）：`observable-macro.md`、`window-management.md`
- 中文标题写在 `title` 里，文件名保持英文，链接更稳定
- 同一目录内文件名唯一；避免空格和特殊字符

## 4. 链接

- 笔记之间优先使用 Obsidian 风格双链：`[[swift/swiftui/observable-macro]]` 或带显示文字 `[[swift/swiftui/observable-macro|@Observable 宏]]`
- 链接到标题：`[[note#小节标题]]`
- 外部链接用普通 Markdown：`[文字](https://...)`
- 写完笔记后在 `related` 里补上最相关的 1–5 篇，图谱和反向链接会更有用

## 5. 图片与附件

- 新图片放在 `content/assets/<主题>/` 下，文件名英文：`assets/swift/navigation-split-view.png`
- 引用方式：`![[assets/swift/navigation-split-view.png]]` 或 `![说明](../assets/swift/navigation-split-view.png)`
- 不再使用外部图床（PicGo）

## 6. 其他写法

- 提示框用 Obsidian callout：`> [!note]`、`> [!tip]`、`> [!warning]`，折叠用 `> [!example]-`
- 代码块注明语言：```` ```swift ````
- 草稿：在 frontmatter 写 `draft: true`，或放进 `private/` 目录（不会被发布）
